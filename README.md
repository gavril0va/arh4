частота меняется, потому что процессор сам подстраивается: когда ему нечего делать — экономит энергию, а когда нужно считать — разгоняется сильнее.

## Итоговый вопрос

у компьютера 4 физических ядра, но программа пишет 8 и это не ошибка. просто на каждом ядре могут работать по два виртуальных потока (из-за Hyper-Threading). поэтому Windows видит 8 «виртуальных» процессоров, хотя железа там на 4.

## Контрольные вопросы

1. **Что показывает Environment.ProcessorCount?** 
 сколько процессоров (логических) программа может использовать для работы.
2. **Чем физическое ядро отличается от логического процессора?** 
ядро — это настоящая железка внутри процессора. а логический процессор — это как бы «виртуальный работник» (иногда их 2 на одно ядро).
3. **Почему увеличение потоков повышает загрузку CPU?**
потому что больше задач начинают выполняться одновременно на разных ядрах.
4. **Почему после определённого количества потоков рост замедляется?**
потому что все ядра уже заняты. Новым потокам негде работать, они просто ждут своей очереди.
5. **Почему частота процессора меняется?**
чтобы экономить электричество и не перегреваться. Нужно считать — частота растет, не нужно — падает.

## Итоговый вывод

программа показала, что у меня 4 логических процессора. один поток загружает процессор только на четверть, потому что работает только одно ядро. когда я запустила 4 потока, загрузка стала 100% — заработали все ядра, а когда запускала 8 или 16 потоков, загрузка оставалась 100% потому что ядра уже были заняты.
 потоки нужно запускать по количеству ядер, иначе толку не будет.
